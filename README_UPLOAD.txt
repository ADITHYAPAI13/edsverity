This folder is a public static website. Upload the CONTENTS of this folder into your GitHub repository root, overwriting existing HTML files. Upload the static folder contents into the existing static folder. Keep backend/ untouched.

Do not upload this README if you prefer not to.

IMPORTANT: Sign in / Sign up use existing Supabase Auth via static/edsverity-auth.js. No secret keys are included. Email verification remains on Supabase. Dashboard, portfolio, project and job CRUD are not connected yet; sample content remains demo-only.

To replace old files in GitHub browser use the same filenames and confirm overwrite; if GitHub does not offer overwrite by upload, use github.dev (press . in repository) to copy/rewrite all files, commit.

After commit check GitHub Actions > Pages, then hard refresh. Test /index.html, /about.html, /register.html and /login.html.
